# assets/

`assets/banner.png` is the plugin's README banner, displayed at the top of the root `README.md`.

- **Generated, not drawn.** Rendered on a local ComfyUI instance with the **FLUX.1 [dev]** (fp8)
  diffusion model at 1536×640.
- **Text overlaid deterministically.** The wordmark "Skill Rollback Guard", the eyebrow
  "SAFE SKILL OPERATIONS" and the tagline "Clean recovery. Trusted skills." are composited on top
  of the raw render (diffusion text is unreliable), so the wording is exact and reproducible.
- **Not MIT.** The MIT licence in the repository root covers the plugin source only. The FLUX.1
  [dev] model weights are released under the FLUX.1 [dev] Non-Commercial License; see the
  "Artwork" section of the root `README.md` for the output-usage note.
